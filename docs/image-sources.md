# Sources des images

## Phase 2 — renforcement des offres

Aucune image externe n’a été ajoutée pendant cette phase. Les photographies locales existantes, déjà distinctes pour chaque prestation et chaque formation détaillée, ont été conservées.

La provenance des fichiers antérieurs n’est pas réattribuée ici sans source vérifiable. Toute future image provenant d’une banque d’images devra être documentée avec la page d’utilisation, le nom du fichier local, l’URL source, l’auteur disponible et la licence.
