# LIDA Solutions & Consulting

Site officiel de LIDA Solutions & Consulting pour présenter ses cinq pôles d'expertise : conseil, digitalisation, organisation, accompagnement ISO et formation professionnelle.

## Développement

```bash
npm install
npm run dev
```

Le serveur de développement utilise Next.js avec Webpack pour assurer un aperçu local stable.

## Vérification

```bash
npm run lint
npm run build
```

## Aperçu de production

```bash
npm run build
npm run start
```
